=============================================================
PANDUAN APLIKASI FIRDAUS SERVIS UNTUK PC & LAPTOP (WINDOWS)
=============================================================

Aplikasi ini dapat langsung dijalankan di PC atau Laptop dengan OS Windows (Windows 7, 8, 10, 11) secara 100% OFFLINE tanpa perlu instalasi rumit (Portable).

-------------------------------------------------------------
CARA MENJALANKAN (SANGAT MUDAH):
-------------------------------------------------------------
1. Cukup klik ganda (double-click) file:
   👉 FirdausServis.exe
   (Atau file Buka-Aplikasi.bat)

2. Aplikasi akan otomatis terbuka dalam jendela aplikasi desktop mandiri (tanpa address bar browser), siap digunakan untuk transaksi kasir POS, penerimaan servis, cetak nota, dan laporan keuangan.

3. Di sudut kanan bawah taskbar (System Tray), akan muncul ikon Firdaus Servis. Anda bisa klik kanan ikon tersebut untuk:
   - "Buka Aplikasi" (Membuka kembali jendela jika tertutup)
   - "Buka di Browser Biasa"
   - "Keluar Aplikasi"

-------------------------------------------------------------
CETAK NOTA STRUK & FAKTUR A4 DI PC / LAPTOP:
-------------------------------------------------------------
- Printer Thermal USB / Bluetooth:
  Pilih tombol "Cetak Struk Roll (58/80mm)". Pada dialog cetak Windows, pilih printer thermal Anda (kertas 58mm atau 80mm).
- Faktur Tanda Terima A4:
  Pilih format "Faktur Resmi A4" lalu tekan tombol Cetak untuk mencetak ke printer inkjet/laser A4 standar atau simpan sebagai PDF.

-------------------------------------------------------------
OPSI INSTALASI PERMANEN PWA (SHORTCUT DESKTOP):
-------------------------------------------------------------
Jika Anda membuka aplikasi melalui browser Google Chrome atau Microsoft Edge:
1. Klik ikon "Install Firdaus Servis" (ikon komputer dengan panah ke bawah) di ujung kanan address bar.
2. Klik "Install".
3. Ikon Firdaus Servis akan otomatis muncul di Desktop dan Start Menu Windows Anda!

Terima kasih atas kepercayaan Anda menggunakan Firdaus Servis.
