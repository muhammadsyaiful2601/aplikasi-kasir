## 2. Fitur per layar

- **Beranda**: pencarian nota/pelanggan/HP/IMEI, hero "Tanda Terima Servis Baru!", grid Fitur Utama (Servis Masuk, Kasir, Stok, Garansi, Cetak Nota, Laporan, Backup, Lainnya), banner "HP Selesai Siap Diambil", Servis Aktif Terbaru, 4 kartu (Antrean Servis, Siap Diambil, Stok Menipis, Kas Hari Ini).
- **Daftar Servis**: pencarian, chip filter 7 status, kartu dengan ubah status cepat / detail / bayar / WA / hapus, modal Ubah Status (8 status), Pelunasan Kilat (Tunai/Transfer/QRIS).
- **Penerimaan Servis**: nomor nota otomatis, template cepat HP (Ganti LCD, Baterai, Konektor Cas, Matot/Air, Flash, Bypass FRP, Speaker/Mic, Kamera) & PC/Printer (Install Windows, SSD/RAM, cleaning, No Display, keyboard/layar/engsel, Paper Jam, Head Buntu, Reset Ink Pad, Infus, Ganti Head, Matot Printer) tersimpan di localStorage `firdaus_custom_service_templates_hp|_pc`; form pelanggan, perangkat, keluhan, biaya + modal, estimasi untung, garansi (0/3/5/7/14/30 hari), teknisi.
- **Detail Servis**: status & pembayaran, 8 tombol status, ubah teknisi/garansi, rincian Jasa (LABOR) & Sparepart dari stok (PART), input modal, riwayat pembayaran + DP, aksi Hapus/WA/Cetak Nota.
- **Kasir**: pencarian produk/SKU/barcode + kategori, grid produk dengan badge stok, keranjang sticky, checkout Tunai/Transfer/QRIS Manual, uang diterima + pecahan, kembalian, validasi kurang bayar, nama pelanggan.
- **Stok**: sub-tab Katalog/Riwayat Mutasi, Opname, Tambah/Edit/Hapus produk (kategori: Aksesori/Sparepart/Baterai/LCD/Kabel & Charger/Tinta & Toner/Lainnya), peringatan modal > jual, riwayat `+n/-n` dengan previous→new stock.
- **Kas & Laporan**: periode Hari Ini/Kemarin/7 Hari/Bulan Ini/Semua; Saldo Kas Bersih, Total Kas Masuk, Modal Barang & Part, Pengeluaran, Total Laba Bersih; kartu Laba Kotor Kasir, Laba Bersih Servis, Sisa Piutang, Pengeluaran; Produk Terlaris; rincian kas servis & biaya; Ekspor CSV Penjualan/Servis; form pengeluaran & modal part.

## 3. State Management

- `useState` + props drilling (tanpa Context/Reducer). State di `Cb`: `e` isReady, `s` initError, `Y` pesan splash, repositori, `_` settings, `M` tab aktif, `N` history tab, `F` badge, `L` **refreshTrigger**, `x` modal servis baru, `K` serviceId, `ee` modal nota.
- **Pola refresh**: `T()` (17200) → reload settings + badge + `O(oe => oe+1)` (naikkan `L`). `hb`/`fb` punya `useEffect(..., [refreshTrigger])` → reload data. Mutasi di modal panggil `onRefreshList`, lalu `T()` saat modal ditutup.
- Storage lokal: printer MAC `firdaus_selected_bt_printer_mac`, template servis, sesi trial (sessionStorage + localStorage).
- Navigasi state-based `M` + history `N`; back button Android via `_g` (17182) melakukan `pop()`.

## 4. Alur kerja utama

### Kasir
`vb` muat produk → klik produk → keranjang (qty ≤ stok) → "Bayar Sekarang" → `yb` (metode, uang diterima, kembalian, nama) → `vb.Q` → `generateNextInvoiceNumber()` + `createSale()` (transaksi: cek stok, INSERT sales/sale_items/payments, UPDATE stok + movement) → buka modal nota `ub`.

### Servis
`gb` terima (template + form) → `findByPhone()`/buat customer → `serviceRepo.create()` (DITERIMA, UNPAID) → `fb` pantau & ubah status → `bb` tambah Jasa/Sparepart (`addItem`: potong stok + movement) → `addPayment()` (DP/lunas) → status SUDAH_DIAMBIL (`updateStatus`: auto-buat garansi ACTIVE) → `Eb` klaim garansi → `ub` cetak/WA nota.

## 5. Bootstrap

1. `createRoot(...).render(<StrictMode><Cb/></StrictMode>)`.
2. `C()` (17121): timeout 20 detik → `It.init()` → `dg(It)` (seed) → `flushWebPersistence()` → settings + badge → ready → auto-backup harian. Global `window.onerror`/`unhandledrejection`.
3. Splash "Memuat FirdausServis..." dengan teks progres; error → "Gagal Membuka Database" + "Coba Lagi".
4. Native Capacitor: StatusBar overlays=false, background `#ffffff`, style Light; splash native ditutup.
5. **PIN gate tidak ada**; `mb = ()=>null`; hanya gate waktu Trial.
6. Routing state-based (bukan hash router). Sub-halaman "Lainnya" memakai state lokal `Tb`.
